# 軟式野球バット適性診断 — プロダクト仕様

## Product overview

軟式野球プレーヤーが7つの質問に答えると、US-1 / US-3 / US-4 / US-5から自分に合うバットを短時間で見つけられる、モバイルファーストの静的診断ツール。診断の根拠を結果とともに示し、商品ページへ自然に進めるようにする。

US-2は仕様情報が未確定のため、初回リリースの診断・比較・結果には含めない。

## Core feature list

1. 1画面1問の7問診断。選択すると次の質問へ進み、戻る操作で回答を修正できる。
2. URLの`ui`クエリで、同じ機能・同じ診断ロジックを2つの外観で表示する。
   - `?ui=maker`: 提携バットメーカーを意識した、力強くクラフト感のある外観。
   - `?ui=unicorn`: `tokyounicorn.netlify.app`を意識した、ダークネイビーとゴールドを主役にしたプレミアムなクラブ調の外観。
   - パラメータがない、または不正な値の場合は`maker`を表示する。
3. 回答ごとの適合度（0〜5）に質問の重みを掛け、モデル別の合計点を計算する。
4. 最高点モデルを基本の第1候補、次点を第2候補として表示する。US-4には長打特化モデルとしての適性ガードを適用する。
5. 結果には推奨理由、向いているプレーヤー、注意点、次点モデルとの選び分け、再診断ボタンを表示する。

### 診断判定

- 各モデルの合計点を算出し、最高点を候補にする。
- 同点は、質問1（最優先したいこと）の適合度が高い方を上位にする。さらに同点ならUS-1を優先する（「迷ったら扱いやすい」を優先）。
- 1位と2位の点差が6点以上なら「明確におすすめ」、3〜5点なら「おすすめ・次点も確認」、0〜2点なら「僅差・比較して選ぶ」とする。
- **US-4適性ガード**: US-4が最高点でも、次の2条件を両方満たさなければ第1候補にはしない。
  1. 質問2で「強いトップバランス」または質問7で「強いトップバランスでも問題ない」を選択している。
  2. 質問1で「とにかく飛距離」、または質問3で「ヘッドを走らせて強く振り切る」、または質問6で「ビヨンド／レガシーのトップバランス」を選択している。
- US-4がガードにより外れた場合は、次に高いUS-1 / US-3 / US-5を第1候補にし、US-4は「長打特化の次点」として比較欄に残す。

| モデル | 結果の主訴求 | 注意・比較案内 |
|---|---|---|

| US-3 | トルピード形状、グリップ寄り重心、タイカップ寄り。ミート性能と口コミ評価が強み。 | より飛距離を狙い、少し難しさを許容するならUS-5。 |

## Sprint plan

### Sprint 1 — 診断体験の完成

- 7問の回答、進捗、前後移動、採点、US-4適性ガード、結果画面、再診断を実装する。
- すべての質問に回答しない限り結果を表示しない。
- 回答を戻って変更した場合は、最新の回答だけで再集計する。

### Sprint 2 — 2テーマと結果の納得感

- `?ui=maker`と`?ui=unicorn`でテーマを切り替える。
- テーマ切替で質問・配点・結果モデル・文言の意味を変えない。
- 得点差ラベル、推奨理由、次点との選び分けを完成させる。

### Sprint 3 — 公開前の品質確認

- スマホ幅を中心にレイアウト、キーボード操作、表示崩れ、主要な回答パターンを検証する。
- 商品URLが未確定なら、商品導線は明確なプレースホルダー表示にし、実在しないリンクを置かない。

## UI/UX requirements

### 共通

- スマホを最優先（幅320px以上）。PCでは読みやすい中央カラムにする。
- 質問画面は「質問番号 / 7」と進捗バー、質問文、選択肢カード、戻る操作を常に分かりやすく示す。
- 選択肢はタップ領域44px以上。選択状態を色だけに依存せず、枠・チェック・文字でも識別する。
- 画面遷移は短く抑え、現在の回答やスクロール位置を見失わせない。
- 結果ではモデル名を最も目立たせ、その直後に「なぜあなたに合うか」を最大3点で示す。点数自体は内部的に使うが、必要以上に採点感を出さない。
- 診断ロジックと表示テーマを分離し、テーマ追加・配点調整がしやすい構造にする。

### `maker` テーマ

- メーカーの野球バットらしい、タフで本格的なクラフトの世界観。ブラックと白を主軸に、ブロンズをアクセントとして使う。
- 木目・バレル・スイングの軌跡を連想させる控えめな装飾を用い、文字の可読性と操作性を優先する。
- 見出しは力強く、回答カードや結果カードはスポーツギアのように輪郭を明快にする。
- Instagramの写真・ロゴ・投稿画像は、権利確認済みの提供素材がない限り使用しない。

### `unicorn` テーマ

- 参照サイトのダークネイビー/チャコール背景とメタリックゴールドの印象を受け継ぐ、プレミアムなアスレチッククラブの世界観。
- 暗色の余白にゴールドの細い罫線、エンブレムを思わせる幾何学フレーム、端正な大文字見出しを用いる。過度なグラデーションやポップな丸角カードは避ける。
- makerの「バットをつくる工房感」と区別し、unicornは「選手が所属したくなる上質なクラブ感」を軸にする。
- 結果表示は発見の高揚感を演出しつつ、スポーツ用品の選択に必要な情報の優先順位は守る。
- 参照サイトの素材・ロゴ・固有コピーを複製しない。雰囲気のみを解釈する。

## Non-functional requirements

- 静的HTML/CSS/JavaScriptのみで動作し、初回公開時にサーバー、AI、ログイン、DBを必要としない。
- JavaScript無効時は診断不能であることを簡潔に案内する。
- 外部フォントや画像の読み込み失敗でも、内容と診断操作が成立する。
- ボタン・選択肢はキーボード操作でき、フォーカス状態を明確にする。見出し構造、ラベル、十分な文字コントラストを満たす。
- 個人情報の入力・保存は行わない。初版では回答の分析送信もしない。
- URLクエリの値は表示用途として安全に扱い、想定外の値を画面へ注入しない。

## Constraints and out-of-scope items

- US-2の診断追加は、形状・重心・グリップ・推奨ユーザー・サイズ展開の確定後に行う。
- 購入・在庫・価格・配送・決済・会員登録・回答履歴・管理画面・A/Bテスト・AIチャットは初版の対象外。
- 身長やポジションだけでバット長を自動決定しない。US-1のサイズ展開は表示するが、長さの個別推薦は追加要件が決まってから扱う。
- `ui`パラメータは見た目の切替のみ。診断ロジックやランキングをテーマごとに変えない。

## Acceptance criteria

1. `?ui=maker`を開くとmakerテーマ、`?ui=unicorn`を開くとunicornテーマが表示され、質問・選択肢・診断結果は同一ロジックである。`?ui=other`およびパラメータなしはmakerテーマになる。
2. 7問のいずれも未回答のまま結果へ進めず、1問ずつ選択・戻る・回答変更ができる。変更後の結果は変更後の全回答で算出される。
3. 「飛距離最優先 / 強いトップバランス / ヘッドを走らせる / 重さを感じたい / 細め＋小さめエンド / ビヨンド・レガシーのトップ / 強いトップでも問題ない」の回答ではUS-4が第1候補となる。
4. 「ミート・打率 / グリップ寄り / コンパクト / 振りやすさ / タイカップ / トップだが扱いやすくしたい / 扱いやすい方がよい」の回答ではUS-3が第1候補となる。
5. 「両立 / 少しヘッドが効く / 状況で使い分け / まだ分からない / こだわりなし / 初めて / 扱いやすい方がよい」の回答ではUS-1が第1候補となる。
6. 「飛距離 / 少しヘッドが効く / ヘッドを走らせる / 重さを感じたい / 細めでエンドの安心感 / バランス型・ミドル / 操作難度を許容」の回答ではUS-5が第1候補となる。
7. US-4が最高点でも適性ガードの2条件を満たさない場合、US-4を第1候補にせず、「長打特化の次点」として注意つきで表示する。
8. 結果画面には第1候補、推奨理由、注意点、次点モデル、得点差に応じた案内、再診断操作がある。US-1結果では83.5 / 84.5 / 85.5cmを表示する。
9. 幅320px以上で横スクロールがなく、すべての選択肢と主要操作がタップできる。キーボードでも選択肢の選択・移動・再診断ができる。
10. Instagramおよび参照サイトのロゴ、投稿画像、固有コピーを無断利用しない。
